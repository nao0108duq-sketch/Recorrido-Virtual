# Recorrido-Virtual
Recorrido virtual por espacios, reales o ficticios, usando por lo menos textos, imágenes e hipervínculos.

# EN TRANSMILENIO PASAN COSAS BUENAS
cada vez que entro al transmi hay un anuncio y una voz que dice “EN TRANSMILENIO PASAN COSAS BUENAS” y me parece un chiste o un poco irónico considerando todas las problemáticas que hay dentro del sistema y que se entrelazan con los problemas de la ciudad: 
Acoso sexual.
Robos e inseguridad.
Informalidad y trabajo.
Largas jornadas y tiempos de desplazamiento.
Congestión y problemas de movilidad.
Otras situaciones relacionadas con la vida cotidiana en la ciudad.

Con este recorrido pretendo explorar las diferentes problemáticas que pueden aquejar a las personas al tomar todos los dias este sistema de transporte.

## ESTRUCTURA DE LA PAGINA
En la página principal aparecerá una imagen del bus con diferentes pasajeros. Al pasar el cursor sobre cada persona aparecerá una pequeña nube de pensamiento que mostrará una experiencia o problemática.

Al hacer click sobre cada pasajero, el usuario podrá acceder a una nueva página donde se desarrollará el tema de manera más informativa, utilizando fotografías, videos, datos, testimonios e hipervínculos.

De esta manera, el bus funcionará como una representación de la ciudad: muchas personas, historias y problemáticas compartiendo el mismo espacio..
